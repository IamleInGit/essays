### 写作约定

自己定的规矩，用来防止写成一锅粥：

- **一篇只讲一件事**，标题就是结论，不是话题
- 顺序固定：我遇到的问题 → 怎么解决 → 下次怎么避免
- 引用书里的原话不超过一两句，其余用自己的话
- 涉及公司项目的一律脱敏，只写「某 MCU」「某个场景」，不写型号、客户、内部代号
- **不放电子书文件**，只写自己的理解，引用不超过一两句
- 不追求篇幅，能删就删
